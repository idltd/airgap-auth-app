Security, storage and updates

People verification proves possession of previously paired keys. Pair in person, compare both check codes, and associate the keys with the person present. Remote relaying and compromised unlocked devices remain possible.

The phone checks the paired site's secret. A live phishing proxy can still relay both codes. Always compare the displayed origin with the browser address bar.

The website signs you in before you check its response. It cannot know whether you completed that final check.

Clearing browser data or losing this device loses credentials. No backup or export is provided. Local removal does not revoke the credential at the website.

A compromised deployment, script, dependency or service-worker update can misuse unlocked secrets. JavaScript cannot guarantee memory erasure.
